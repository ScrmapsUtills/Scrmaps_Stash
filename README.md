# SCRMaps Stash

SCRMaps **직업키우기 2**에서 아이템 코드 스크린샷 여러 장을 보관함에 순서대로 등록하고, 선택한 룬을 원하는 개수만큼 상점에 판매하는 Chrome 확장 프로그램입니다.

## 설치

1. `SCRMaps-Stash.zip`의 압축을 풉니다.
2. Chrome 주소창에 `chrome://extensions`를 입력하고 **개발자 모드**를 켭니다.
3. **압축해제된 확장 프로그램을 로드합니다**를 누르고 `manifest.json`이 들어 있는 폴더를 선택합니다.
4. SCRMaps에 로그인하고 [캐릭터·보관함](https://www.scrmaps.com/class-rpg?tab=stash)을 엽니다. 이미 열려 있다면 탭을 새로고침합니다.

## 아이템 일괄 등록

1. 보관함 등록 화면에서 오른쪽 **보관함 일괄 등록**을 펼칩니다.
2. **아이템 코드 사진** 칸에 등록할 스크린샷을 끌어놓습니다.
3. **인증 코드 사진** 칸에 게임에서 아이템을 보관한 뒤 받은 인증 스크린샷을 넣습니다.
   - 아이템마다 인증 코드가 다르면 아이템 사진과 같은 수의 인증 사진을 넣습니다.
   - 인증 코드 하나를 함께 쓰면 인증 사진 한 장을 넣고 **같은 인증 코드로 모두 등록**을 체크합니다.
4. 화면에 나온 파일 짝을 확인하고 **순서대로 등록**을 누릅니다. 두 사진 목록은 각각 파일명의 숫자 순서로 정렬됩니다.

확장이 **다른 사진 고르기**로 다음 사진을 넣고, 사이트에서 코드를 인식하면 **보관함에 등록**을 누릅니다. 이미 등록된 아이템은 건너뜁니다. 이전 성공 문구가 남아 이번 등록 결과를 구분할 수 없으면 **결과 미확인**으로 집계하고 다음 사진으로 넘어갑니다. 미확인 항목은 다시 등록하기 전에 보관함을 확인하세요.

## 룬 판매

1. 보관함에서 판매할 룬을 클릭합니다.
2. 오른쪽 **룬 판매**를 펼치고 판매 개수를 입력합니다.
3. 표시된 룬 이름과 가격을 확인한 뒤 **같은 룬 판매**를 누릅니다. 진행 중에는 **중지**를 누를 수 있습니다.

예를 들어 **말 룬을 4개** 보유했을 때 `2`를 입력하면 2개를 팔고, `99`를 입력하면 가진 4개를 모두 팝니다.

확장은 매번 룬 이름과 판매 가격을 확인한 뒤 사이트의 **팔기** 버튼을 누릅니다. 연속 판매 시에는 사이트의 남은 시간과 버튼 활성화 상태를 따릅니다. 남은 시간이 표시되지 않으면 직전 룬이 보관함에서 빠진 시점부터 10초를 기다립니다.

## 업데이트

새 버전의 압축을 기존 확장 폴더에 덮어씁니다. `chrome://extensions`에서 확장을 새로고침한 뒤, 열려 있는 SCRMaps 보관함 탭도 새로고침합니다.
